# 13. Перевірка бібліотеки

Перед включенням дистиляту в канон запусти:

```bash
python scripts/distill_delta.py path/to/knowledge
```

Preflight вимагає абсолютну дату `ДД.ММ.РРРР`, wikilink-провенанс і `⚠️` для
непевних тверджень. Skill `skills/library-check/SKILL.md` описує людський/агентний аудит.
Скрипт лише звітує й ніколи не переписує ноти автоматично.
