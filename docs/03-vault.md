# 03 — Memory-граф і Obsidian master-vault

## Master-vault через symlinks

ОДИН Obsidian-vault (`vault.root` з config.toml), у який symlink-аються всі бази:

```
SecondBrain/
├── _HOME.md            ← точка входу для ЛЮДИНИ
├── log.md              ← append-only журнал операцій
├── inbox/              ← реальна тека: сирі надиктовки людини
├── memory  → (symlink) ← memory-граф (ядро)
├── chatgpt-archive →   ← конвертовані архіви
├── gemini-archive  →
└── claude-archive  →
```

Файли фізично лишаються на місцях — librarian, хуки і скрипти нічого не помічають.
🔴 НЕ переносити файли фізично і не міняти шляхи в config після індексації без
потреби — symlinks існують саме для цього.

## Memory-граф: одна нота = один факт

- Тека **пласка** (без підтек). Ім'я: `snake_case` з префіксом типу:
  `project_` (проєкти/справи) · `ref_` (довідкове) · `feedback_` (правила «як працювати»,
  виведені з фідбеку) · `issue_` (технічні проблеми) · `idea_` (ідеї) · `user_` (про людину) ·
  `hub_` (хаби доменів).
- Frontmatter обов'язковий (шаблон: `templates/memory-note.template.md`);
  `name:` == імені файлу без `.md`.
- **Хаби** — людський шар навігації: 3–6 нот `hub_<домен>` під домени життя людини +
  `_HOME.md` з лінками на хаби. Кожна нота має ≥1 uplink на свій хаб (футер
  `> Uplink: [[hub_…]]`), хаб — зворотний лінк. Так у graph view немає нот-сиріт.
- **MEMORY.md** — індекс: один рядок на ноту (`- [Назва](file.md) — гачок`),
  ніколи не зміст. Це єдиний файл memory, що вантажиться в контекст щосесії —
  тримай його < ~17 КБ.

## Wikilink-політика

- Ноти між собою: `[[назва_ноти]]`.
- Крос-базові лінки (memory → чат-архів): теж wikilink — резолвляться в межах
  master-vault (`[[2026-06-01_Назва_чату_abc123]]`).
- Директорії і скіли — НЕ wikilink (бектики: `chats`, `lean-mode`) — на них нема .md-ноти.
- Перевірка цілісності: `python scripts/sanitize.py --audit` → 0 битих лінків.

## Inbox: raw → processed

Людина кидає сирі надиктовки/нотатки в `inbox/` як вміє. Обробка моделлю:
витягти сенси в memory-ноти → у сирому файлі проставити `status: processed`
(+`processed_date`, `processed_by`, блок «Розфасовано у: [[ноти]]»). Сирий файл
**не видаляти** — це першоджерело-якір, і він лишається в індексі з банером сирого.

## Ритуал нової ноти (кожного разу)

1. Файл snake_case з префіксом + повний frontmatter.
2. ≥1 uplink на хаб + [[паралелі]] до сусідів (кандидатів підкаже memory_lint-хук).
3. Рядок у MEMORY.md у розділі відповідного хаба.
4. Кожен факт — з абсолютною датою ДД.ММ.РРРР.
5. Реіндекс: `librarian.py index --source memory` (частина запису, не «потім»).
