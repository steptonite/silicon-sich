# 05 — Хуки харнеса: дисципліна в залізі

Ключова ідея: правило, яке тримається на сумлінності моделі, помре після першого
компакту. Хук харнеса виконується ЗАВЖДИ. Чотири хуки закривають чотири діри пам'яті.

> Ці хуки — під **Claude Code**. Codex влаштований інакше (є подія PostCompact,
> харнес віддає телеметрію) — його адаптер компакт-щита описано в
> [18-codex-hooks](18-codex-hooks.md).

## semantic_recall (UserPromptSubmit)

На КОЖНЕ змістовне повідомлення людини (від 12 символів, не slash-команда) хук
запускає hybrid search у JSON-режимі та вкидає до трьох збігів. Confidence рахує
retrieval-core: сильним може стати лише курований результат із достатньою
vector-релевантністю та/або згодою vector+keyword. Raw-збіг залишається фоном навіть
за малої дистанції — це захист від анкерингу на старому чаті.

Якщо всі збіги з одного файла, хук забороняє звужувати пошук до нього. Слабкі
збіги вимагають 2–3 переформулювання й source/keyword-фолбек. Збій не ламає
сесію: деталь пишеться в локальний diagnostic log, а модель один раз за сесію отримує
`semantic recall unavailable` і не має права вигадувати минуле з пам'яті.

## memory_lint (PostToolUse на Write|Edit)

Модель записала ноту в memory → хук перевіряє канон (frontmatter, uplink на хаб,
≥2 wikilinks, дата ДД.ММ.РРРР, рядок у MEMORY.md). Порушення → модель ОДРАЗУ отримує
чек-ліст що дофіксити + семантичні кандидати на [[паралелі]] (librarian підказує
сусідів по сенсу). Ноти-«острови» стають неможливими.

## pre_compact (PreCompact)

Два хуки на цю подію. Перший (`pre_compact.sh`) фоново доіндексовує транскрипти
сесій — усе сказане вже лежить у векторній базі до того, як компакт його зітре.

Другий (`pre_compact_snapshot.py`) — **anti-compact safe**: детермінований зріз стану
незалежно від того, чи модель ще «при пам'яті». Перед стисненням він записує
ефемерний `compact_checkpoint.md` (обов'язки на зараз, дослівні останні промти,
робочі шляхи, курований `bridge.md ## ЗАРАЗ`) + рядок audit із машинним прапорцем
`degraded`. $0, без LLM, без мережі; будь-яка біда → тихо виходить 0, компакт не
ламається. Тири впорядковані за пріоритетом: те, чого після компакту нема більше
ніде (обов'язки + дослівні промти), — згори, verbose bridge — в кінець.
⚠️ PreCompact НЕ вміє additionalContext (stdout порожній) — зріз повертає назад
`session_start`, а не сам цей хук.

## session_start (SessionStart)

Нова сесія стартує з інжектом: зріз `bridge.md` (гарячий стан минулої сесії — задача,
шляхи, рішення+чому, наступний крок) + залізні правила пам'яті + готова команда
librarian. Модель прокидається не з амнезією. Якщо PreCompact щойно (≤2 год) лишив
`compact_checkpoint.md`, хук вкидає і його блоком відновлення; якщо той зріз був
`degraded` (промти не витяглись) — додає попередження звірити `bridge.md` руками.

## Установка

1. Відкрий `scripts/hooks/settings-hooks.example.json`, заміни `<KIT>` на абсолютний
   шлях кита.
2. Злий блок `hooks` у `~/.claude/settings.json` (якщо там уже є хуки на ці події —
   додай у масив, не заміняй).
3. 🙋 Перезапустити сесію Claude Code.

## Перевірка

- Нова сесія → бачиш «ВІДНОВЛЕННЯ СЕСІЇ … bridge.md».
- Змістовне повідомлення → «🧠 АВТО-ПРИГАДУВАННЯ» з 1–3 хітами.
- Запиши тестову ноту без лінків → прилетить «📐 КАНОН VAULT…» з чек-лістом.
