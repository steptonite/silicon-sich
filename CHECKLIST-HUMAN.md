# Чек-ліст для людини 🙋

Все інше робить модель за [PLAYBOOK.md](PLAYBOOK.md). Твої кроки:

## Разово, на старті

- [ ] Установити **Ollama** (ollama.com) і запустити застосунок.
- [ ] Установити **Obsidian** (obsidian.md).
- [ ] Замовити експорти (прийдуть на email, від хвилин до доби):
  - [ ] ChatGPT: Settings → Data controls → Export data
  - [ ] Gemini: takeout.google.com → My Activity (Gemini Apps) + NotebookLM
  - [ ] Claude: Settings → Privacy → Export data
- [ ] Розпакувати zip-и в теки, сказати моделі шляхи.
- [ ] Відповісти моделі на 2 питання: як тебе підписувати в архівах і які
      домени твого життя стануть хабами (робота, проєкти, здоров'я, гроші…).
- [ ] Відкрити vault-теку в Obsidian, коли модель скаже.
- [ ] Перезапустити сесію Claude Code після установки хуків.

## Під час дистиляції (етап 6)

- [ ] Проглянути кластери тем, які запропонує модель — поправити своїм знанням життя.
- [ ] Назвати сенситивні кластери (що НЕ має покидати сирий шар).
- [ ] Вибірково перевірити кілька фактів у самарі проти сирих чатів.

## Постійно (хвилини на тиждень)

- [ ] Раз на місяць-два — свіжий експорт чатів (система доконвертує лише нове).
- [ ] Кидати сирі думки/надиктовки в `inbox/` — модель розфасує.
- [ ] Іноді відкривати Obsidian graph view — це твоя карта знань; дивитись, чи
      не з'явились острови.
- [ ] Ловити модель на «записав» без показаного шляху файлу — це головна дірка
      дисципліни. Вимагай доказ.
