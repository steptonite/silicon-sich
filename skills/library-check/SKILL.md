1. Запусти `python scripts/distill_delta.py <тека>`.
2. Для кожного твердження перевір абсолютну дату, wikilink на першоджерело і провенанс.
3. Невпевнені висновки позначай `⚠️`; не перетворюй відсутність доказу на негативний факт.
4. Не переписуй ноти автоматично: покажи проблеми людині або виконавцю.
